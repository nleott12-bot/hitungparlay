CASTOTO MIX PARLAY CALCULATOR
==============================
File utama: index.html

Cara pakai:
1. Extract ZIP.
2. Buka index.html di browser.
3. Background dan logo sudah berada di folder assets/.
4. Form berada sebagai overlay transparan di atas background, sehingga background asli tidak diganti/didobel dengan screenshot form.

Catatan:
- background.png = background yang Anda berikan.
- castoto-logo.png = logo yang Anda berikan.
